---

Before doing any work, orient yourself in this repository and confirm the lane with me.

1. Read `AGENTS.md` completely.
2. Read `team/README.md` and ask which lane I am working in if it is not obvious from the
   conversation.
3. Read that person's brief at `team/<slug>/README.md` and their `tasks.md`.
4. If `graphify` is installed, ask the graph rather than reading files at random:
   `graphify query "<what I am about to work on>"`. If it is not, read
   `docs/field-dictionary.md` and `core/contracts.py` — between them they explain most of
   the system.

Then tell me, in five lines: which lane, which directories I may touch, which gates apply
to a change here, and what the top uncompleted task in `tasks.md` is. Ask me to confirm
before starting.
