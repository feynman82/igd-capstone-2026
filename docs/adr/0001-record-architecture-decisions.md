# 1. Record architecture decisions

Date: 2026-09-08 · Status: accepted

## Context
Five people and their coding agents will make choices across nine weeks. Undocumented
choices get re-litigated, and an agent with no record of a decision will cheerfully make a
different one next session.

## Decision
Every non-obvious choice gets a short ADR here, numbered, in this format. An ADR is half a
page. It records what we chose, what we rejected, and why — not how to implement it.

## Consequences
The report's technical chapter is largely assembled from these. Writing them as we go is
cheaper than reconstructing them in November.
