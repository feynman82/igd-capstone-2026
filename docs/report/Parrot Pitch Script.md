- More packs, same recipe

**Say:**

Why call this a platform and not an app? Because we built the hard part once. The engine in the middle files documents, finds the right page, checks the answer against it and cites it. Everything else plugs in from two directions. Skills, like reminders, alerts and advice, read the facts the engine has filed; none of them touches the screen. Subject packs, like tax and insurance, teach the engine a field of expertise. A pack is one file of know-how, so adding one means writing, not rebuilding. One rule keeps the advice honest: every figure in an advice or a reminder is worked out by ordinary code from records it can cite. The AI explains the sum. It does not do it. So far: thirty-six reviewed changes merged, two hundred and thirty-one saved versions of the code, and nine hundred and eleven automatic checks passing.

## 15 · Yew Mun

**On screen:** 0.76→0.52

- THE FINDING
- Better search made it worse at saying 'I don't know'.
- More documents meant every trick question found a page that looked close but didn't answer it. Shown a close page, it answers.
- Fix tried: make it pickier. 'I don't know' rose 0.52 → 0.64, but sticking to the page fell 0.967 → 0.809. Rejected by measurement (ADR 0019).

**Visual:** `15-abstain.png`

**Say:**

This is the finding we would stake the mid-term on. Better search made PARROT worse at saying 'I don't know'. How can that be? With six documents, a trick question usually found nothing remotely relevant, so the system declined. With twenty-six, almost every trick question finds a page that is close. Ask about road tax and you get the car insurance schedule: it mentions the car, but not the road tax. Shown a close page, it answers from it. So we tried the obvious fix: make it pickier about which pages count. 'I don't know' went up to sixty-four percent, but sticking to the page fell from 0.97 to 0.81. It started refusing good answers and fumbling the ones it gave. A bad trade at every setting, so we measured it, wrote it down, and said no. The lesson: restraint is not a free by-product of accuracy. You have to measure it on its own. And this is the screen we most want you to remember: no electricity bill on file, so it says so, instead of inventing a number.
