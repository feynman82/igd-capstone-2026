# `eval/results/` — committed evaluation runs

**Append-only.** Never overwrite a result.

The trend across weeks 3, 5 and 8 is the finding; a single number is not. Name each run
by date and by what changed:

```
2026-09-22-baseline-dense-only.json
2026-10-06-rrf-plus-rerank.json
2026-10-27-run3-full.json
```

Each run gets a sibling `.md` with one paragraph: what changed, what moved, and whether
that was what you expected. The paragraph you write on the day is the paragraph that ends
up in the report.
